# タスクを始める

決まりは ~/tasks/README.md にある。まだ読んでいなければ先に読む。

1. 題・短い名前・チケット番号・リポジトリを会話から決める。足りないものは本人に聞く。リポジトリは、作業ディレクトリが Git のリポジトリならそれにする
2. `tsuzuki task new <短い名前> --title <題> --ticket <番号> --repo <リポジトリの絶対パス>` で、フォルダーと task.md を作る（決まっていないものは付けない）。tsuzuki が使えなければ、README の形で自分で作る
3. チケットを作るところから始めるときは、文案を作り、本人に確かめてから作る（`gh` が使えれば `gh issue create`、使えなければ本人に作ってもらう）。番号を task.md の `ticket` に書く
4. task.md の `目的` に、やることと完了の条件を書く。チケットがあれば読んで、その要点を書く（`gh` が使えれば `gh issue view <番号>`、使えなければ本人に内容を聞く）
5. 最後に、次の会話に貼れるように `@<task.md の絶対パス>` を本人に示す（tsuzuki の出力の2行目）。パスに空白があれば `@"<絶対パス>"` と書く
