# 引き継ぐ

決まりは ~/tasks/README.md にある。まだ読んでいなければ先に読む。

1. この会話のタスクの task.md を読み直す。どのタスクか分からなければ、`tsuzuki task list` の結果（tsuzuki が使えなければ ~/tasks の直下のフォルダー）を示して、本人に選んでもらう
2. `現在地`・`次の一手`・`待っていること` を、この会話の内容で書き直す。`決めたこと` には、新しく決めたことを足す
3. 見出し情報の `stage` と `waiting` を今の状態に直し、`updated` を `date '+%Y-%m-%dT%H:%M'` の結果にする
4. この会話で作った、タスクのフォルダーの外の資料を `資料` に足す（`- <絶対パス> <説明>` の形で1行ずつ）
5. 書き換えた欄を、本人に短く示す

## 書き方

- 書き直す欄は、箇条書きで3〜7行にする。待っていることがなければ「なし」とだけ書く
- 現在地には、何が終わり、何が途中かを書く
- 次の一手の1行目には、次の会話の最初にすることを書く
